# 夜霧の脱出 v0.4.1 — SOLO STEALTH

[ブラウザで遊ぶ](https://8mahi8.github.io/yorugiri-escape/)

BOTハンターから隠れ、石の音で陽動し、見つかったら地形を使って逃げるオリジナルの2D潜伏ゲーム。
暗号機5台のうち3台を解読して南東ゲートから脱出。HPは2。

## 操作

| 動作 | PC | iPhone / iPad |
|---|---|---|
| 移動 | WASD / 矢印 | 左側の好きな場所をタッチ→ドラッグ（フローティングスティック） |
| 調べる・解読（長押し）・板 | E / Space | 「調べる」を長押し（移動中でも付近の暗号機に自動停止して解読） |
| ダッシュ | Shift | 「ダッシュ」 |
| しゃがみ切替 | C | 「しゃがむ」 |
| 石投げ | R → 地面をクリック | 「石」を狙う方向へドラッグして離す／タップして地面を選択 |
| 投げるのをやめる | R / Esc | 石ボタンを再度タップ |
| 一時停止 | Esc | Ⅱ |

## v0.4.1の操作改善

- スティックを固定位置からフローティング方式へ。指を置いただけでは移動せず、ドラッグした方向に動く。
- 解読中は長押しアクションを優先するため、ジョイスティックの微小入力で解読が止まらない。
- 石を長いスワイプで狙ってそのまま投げられる。従来の二段階照準も維持。
- 投擲照準中も左スティックで移動可能。

## v0.4の追加要素

- 石2個を初期所持、マップ内2地点で各1個補充（最大2個）。
- しゃがみ移動・足音・解読音・ダッシュ音・石の着地音。
- ハンターは5状態（巡回、物音の調査、追跡、目撃地点の捜索、硬直）。
- 視界には壁による遮蔽があり、音を聞いただけでは現在のプレイヤー位置を知りません。
- 直線だけでは追いつかれる速度差（通常175／追跡198）。視線遮断・板・陽動で振り切る設計。
- 板のスタンは使用時の接触判定。無命中なら短時間の障害物。
- 暗号機は約10.5秒/台で解読。中断した進捗は残ります。
