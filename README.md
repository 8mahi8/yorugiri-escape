# 夜霧の脱出 / Yorugiri Escape

追跡者BOTから逃げ、5台の暗号機のうち3台を解読して脱出するオリジナルの2Dブラウザゲーム（試作版 v0.2）。『第五人格』に着想を得ていますが、非公式・独立作品です。

## プレイ

GitHub Pages URL: https://8mahi8.github.io/yorugiri-escape/

Pagesが未設定の場合は、リポジトリの `Settings > Pages > Build and deployment` で `Deploy from a branch`、`main`、`/(root)` を選択してください。

- iPhone・iPad：左側で移動、右側のアクションで解読・操作、ダッシュで加速。
- PC：WASDまたは方向キーで移動、Eまたはスペースで解読、Shiftでダッシュ。

このバージョンはBOT対戦のみです。オンライン対戦サーバーは含みません。ブラウザ環境によりタッチ入力の挙動が異なるため、実機での検証が必要です。
