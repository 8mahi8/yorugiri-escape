# 夜霧の脱出 / Yorugiri Escape

追跡者BOTから逃げ、5台の暗号機のうち3台を解読して脱出するオリジナルの2Dブラウザゲーム（試作版 v0.3）。『第五人格』に着想を得ていますが、非公式・独立作品です。

## プレイ

GitHub Pages URL: https://8mahi8.github.io/yorugiri-escape/

Pagesが未設定の場合は、リポジトリの `Settings > Pages > Build and deployment` で `Deploy from a branch`、`main`、`/(root)` を選択してください。

- iPhone・iPad：左側で移動、右側のアクションで解読・操作、ダッシュで加速。
- PC：WASDまたは方向キーで移動、Eまたはスペースで解読、Shiftでダッシュ。

## v0.3 ソロ向けチェイス調整

- ハンターの視認は前方約140°・275px以内。近距離（約78px）は全方向で認識し、壁越しには見えない
- 視界を扇形で表示し、壁による遮蔽も反映
- 暗号機やダッシュの物音は近距離の調査対象になるが、直接チェイス確定にはならない
- 視線を切って約2秒で追跡記憶が切れる。捜索中は最終目撃位置に向かう
- ハンターの追跡速度169、プレイヤー歩行175。ダッシュの再使用間隔7秒
- 初回被弾後に短時間のハンター硬直、プレイヤー加速、無敵時間を付与

テスト: 通常の視認、背後、壁越し、草むら、音、追跡解除、被弾後回避をブラウザで検証。iPhone/iPad相当のタッチ操作も再検証済み（実機未確認）。

このバージョンはBOT対戦のみです。オンライン対戦サーバーは含みません。ブラウザ環境によりタッチ入力の挙動が異なるため、実機での検証が必要です。
