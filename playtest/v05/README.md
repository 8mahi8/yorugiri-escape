# 夜霧の脱出 v0.5 — 4vs1 試遊版

**URL**: https://8mahi8.github.io/yorugiri-escape/playtest/v05/  
**状態**: ブラウザ自動操作で試験済み、人間の実機Safariでの評価は未完了。**v0.4.1はルートで継続公開**。

- サバイバー4人（プレイヤー1人＋BOT3人）vs ハンターBOT1体。
- 7台の解読対象のうち5台を修復し、2つの出口から脱出する。
- 仲間BOTは解読担当の分担、追跡からの逃走、板の利用、救助、脱出を判断する。
- 拘束と救助、再拘束・脱落、仲間の脱出数による勝敗に対応。3〜4人脱出で勝利、2人で引き分け、0〜1人で敗北。
- 石投げは4vs1の基本動作から除外。チームプレイを主軸として検証する。
- オンライン対戦ではなく、一人用BOT戦。

## 操作

| 操作 | PC | スマホ・タブレット |
|---|---|---|
| 移動 | WASD / 矢印 | 左側タッチ→ドラッグ |
| 修復・救助・板・開門 | E / Space 長押し | 調べるボタン長押し |
| ダッシュ | Shift | ダッシュボタン |
| しゃがみ | C | しゃがむボタン |
| 一時停止 | Esc | 一時停止 |

## テスト概要（Chromiumエミュレーション）

- PC、iPhone縦／横相当、iPad相当、小画面で起動と入力を検証。
- 長押し修復、マルチタッチ移動＋修復、追跡、プレイヤー→BOT救助、BOT→プレイヤー救助、脱出と勝敗判定を検証。
- キーボード操作エージェント9試合：勝利3、引き分け3、敗北3。
- 無操作9試合：サバイバー勝利0。
- 操作エージェントは人間より効率的な可能性がある。**遊びの面白さを証明するものではない**。
